## ✨ Fitur Website (Paket Standar)

- Desain responsive (HP, tablet, desktop)
- Hero + branding sekolah (navy & emas)
- Profil, sejarah, visi misi, kurikulum (tab interaktif)
- Program Plus, Fullday School
- Berita & prestasi
- Galeri kegiatan
- Ekstrakurikuler
- Info PPDB + CTA daftar
- Pendataan alumni
- Kontak + Google Maps
- Footer + credit

## ⚙️ Fitur Panel Admin

- Dashboard statistik & kesehatan website
- Kelola berita & prestasi (editor + publish/draft)
- Kelola galeri foto
- Edit halaman statis
- Kelola ekstrakurikuler
- Atur info PPDB (banner, jadwal, formulir online)
- Pendataan alumni (export Excel)
- Ganti tema warna & teks hero tanpa kode
- Pengaturan kontak, media sosial, keamanan
