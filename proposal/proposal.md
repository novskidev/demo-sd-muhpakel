# 1. Pendahuluan

Di era digital saat ini, website bukan lagi sekadar pelengkap — melainkan wajah utama sekolah di mata publik. Calon orang tua, wali murid, dan masyarakat umum hampir selalu mencari informasi sekolah melalui internet sebelum mengambil keputusan.

SD Muhammadiyah Pakel sebagai salah satu sekolah dasar Muhammadiyah terdepan di Kota Yogyakarta dengan sistem Fullday School berhak mendapatkan representasi digital yang sesuai dengan kualitas pendidikannya.

Proposal ini kami susun untuk menawarkan jasa pembuatan website profil sekolah yang modern, informatif, dan mudah dikelola. Website akan menjadi pusat informasi resmi sekolah yang mencakup profil, program, berita, prestasi, galeri, hingga layanan PPDB (Penerimaan Peserta Didik Baru) online.

**Manfaat website bagi sekolah:**

- Meningkatkan kredibilitas dan citra sekolah di mata publik
- Memudahkan calon orang tua mencari informasi & mendaftar PPDB online
- Pusat informasi resmi: berita, prestasi, agenda, pengumuman
- Mengurangi beban kerja staf dalam melayani pertanyaan berulang
- Media promosi yang dapat diakses 24 jam dari mana saja

# 3. Tujuan Pembuatan Website

Pembuatan website ini bertujuan untuk:

- Menyediakan sarana informasi resmi dan terpercaya bagi sekolah, orang tua, dan masyarakat.
- Memperkenalkan program unggulan (Program Plus, Fullday School, tahfidz) kepada calon orang tua.
- Mendukung proses PPDB dengan formulir pendaftaran online dan informasi kuota real-time.
- Mendokumentasikan berita, prestasi, dan kegiatan sekolah secara terstruktur.
- Membangun citra sekolah yang modern, transparan, dan profesional di era digital.

# 5. Spesifikasi Teknis

| Aspek | Spesifikasi |
| --- | --- |
| Desain | Responsive (HP, tablet, desktop), modern, sesuai branding sekolah |

| Panel Admin | Dashboard: kelola berita, galeri, halaman, PPDB, pengaturan tampilan |
| Customizer | Ganti warna, font, navbar, teks hero tanpa menyentuh kode |
| Keamanan | SSL/HTTPS, proteksi panel admin, backup otomatis |
| SEO | Optimasi mesin pencari (Google), sitemap, meta tags |
| Performa | Optimasi gambar, cache, waktu muat cepat (< 3 detik) |
| Integrasi | Google Maps, WhatsApp, formulir kontak, media sosial |

| Paket | Fitur Utama | Harga |
| --- | --- | --- |

| Paket Standar | Panel admin lengkap + customizer tampilan + PPDB online + notifikasi + backup otomatis + garansi & pelatihan admin 3 bulan | Rp 7.500.000 |
| Paket Lengkap (Rekomendasi) | Semua fitur Standar + multi-admin & hak akses + dukungan prioritas + pelatihan 3 sesi + update konten 3 bulan + SEO & sitemap | Rp 9.500.000 |
